=head1 NAME

MultiSMTP - make OTOBO aware of multiple SMTP servers

=head1 DESCRIPTION

MultiSMTP assigns outgoing SMTP accounts to sender addresses in OTOBO 11.1.
Queues using different system addresses can therefore use different SMTP
servers and credentials. Incoming mail account settings are independent.

The administration screen provides SMTP, SMTPS and STARTTLS profiles, with
Basic, anonymous, XOAUTH2 or OAUTHBEARER authentication. OAuth profiles use
existing OTOBO functional accounts and the native token provider.

After installing the package, configure the profiles and set C<SendmailModule>
to C<Kernel::System::Email::MultiSMTP> in System Configuration. See the
repository README for configuration options, build commands, regression tests,
and the disposition of historical upstream issues.
